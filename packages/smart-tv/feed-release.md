The latest AIOStreams TV apps. See the [smart TV guide](https://docs.aiostreams.viren070.me/apps/smart-tv) for how to install them.

### LG (webOS)

[jinbei-studio-webos.ipk](@BASE@/jinbei-studio-webos.ipk), for Developer Mode. With the Homebrew Channel, add `@REPOSITORY@` as a repository in its settings instead: the app then installs and updates from the TV.

### Samsung (Tizen)

[jinbei-studio-tizen.wgt](@BASE@/jinbei-studio-tizen.wgt), unsigned: the installer signs it for your TV.
